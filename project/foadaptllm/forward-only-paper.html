01 / Overview

Adaptation can start
with the forward pass.

THE PAPERForward-only learningSelective rank reductionInference-time adaptation

Large-scale LLM inference motivates a simple question: can the inference process itself enable efficient task-specific adaptation? This work proposes a forward-only approach that uses activations to identify which weight matrix merits rank reduction.

The method measures the angle concentration of activations induced by each singular value decomposition (SVD) component and compares it with that of the full hidden states. This exposes components with a dispersing effect and guides a search for promising weight matrices. Higher-order components with smaller singular values are then selectively removed, while lower-order components are retained.

Across diverse tasks, the approach offers competitive accuracy with lower estimated peak memory than gradient-based search and lower computational cost than exhaustive search. Extended experiments cover LLMs with up to 57B parameters, alongside applications to fine-tuning and steering prompts.

The key is knowing which weights to reduce—and using forward passes to find them.
Read the original abstract

Large language model (LLM) inference serving is undergoing rapid growth and large-scale deployment, motivating us to rethink how the inference process itself can be leveraged to enable efficient task-specific LLM adaptation. In this paper, we propose a forward-only approach for efficient LLM adaptation with forward-only passes in LLM inference serving. We exploit the angle concentration of activations induced by each singular value decomposition (SVD) component to measure its contribution—dispersed or concentrated—to the angle concentration of the hidden states. Based on this, our forward-only search then efficiently identifies the weight matrix with the highest dispersion that merits rank reduction. We then selectively remove the higher-order components and retain the lower-order components in SVD. Empirical results across diverse datasets demonstrate the competitive accuracy of our forward-only approach, while theoretical analysis shows lower peak memory and greater speedup than the gradient-based approach and greater speedup than the exhaustive search approach. The experiments further present the robustness and generalization of our forward-only approach to various LLMs with up to 57B parameters. The code is included in the supplementary material.

02 / Method

From activation geometry
to selective rank reduction.

Three steps connect a standard forward pass to a task-adapted model. The search uses angle concentration as a heuristic for selecting candidate weights.

01

Observe component activations

Decompose a weight matrix with SVD. The sum of the activations induced by its rank-1 components reconstructs the standard output.

Y = XWT = ∑i Y(i)
Forward activations provide the search signal.
02

Rank weights by dispersion

Compare each component’s angle concentration with the full hidden states. Aggregate negative differences among the last m components.

Δi = AC(Y(i)) − AC(Y)
score(W) = −∑i=r−m+1…r min(Δi, 0)
A larger score identifies a more dispersed candidate.
03

Validate the retained rank

Evaluate rank-reduced candidates. Hierarchical search uses a small validation subset before evaluating the top candidates on the full validation split.

Ŵ = UΣ̂VT
Retain the top k% singular components
Validation accuracy determines the final candidate.
